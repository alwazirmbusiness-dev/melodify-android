🎵 Music App (Android)

A simple and modern Music Player Android application built with Java/Kotlin (depending on your project).
This app allows users to play local audio files with a smooth and lightweight experience.

🚀 Features
🎶 Play local music files
⏯️ Play / Pause / Next / Previous controls
📂 Automatic music scanning from device storage
🎧 Background music playback
🔊 Seek bar support
📱 Clean and simple UI
⚡ Lightweight and fast performance
